## Overview

A responsive Coffeeroasters subscription website built with React, TypeScript, Tailwind CSS, and Vite. The site includes dedicated Home, About, and Create Plan pages with responsive layouts across desktop, tablet, and mobile breakpoints.

The Home and About pages feature responsive hero sections, coffee collections, benefits, process steps, company information, and custom responsive layouts. The About page also includes a fluidly positioned quality section using `CSS clamp()` values to maintain the image overlap, spacing, and text layout across different viewport sizes.

The Create Plan page features an interactive multi-step coffee subscription wizard with selectable options, a dynamically generated order summary, subscription pricing, and an order confirmation modal.

Accessibility was considered throughout the application, including keyboard-accessible navigation, route-based focus management, visible focus states, focus trapping for menus and dialogs, and Escape-key handling.

## What I learned

This project gave me more practice building responsive interfaces with React and Tailwind CSS, particularly using custom `clamp()` values to create fluid layouts across viewport sizes. I also strengthened my understanding of keyboard accessibility, focus management, focus trapping, and accessible dialogs.

## Challenges

One of the main challenges was maintaining the responsive layout of the About page's quality section, where the overlapping image and surrounding content needed to remain consistent across different viewport sizes.

The Create Plan page also required careful state management for the multi-step wizard, dynamic order summary, selectable options, and confirmation modal while maintaining predictable keyboard and focus behavior.

## Continued development

I want to continue improving my approach to responsive design and accessibility, particularly through testing interactions across different browsers, viewport sizes, and assistive technologies.
